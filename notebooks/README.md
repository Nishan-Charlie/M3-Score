# MRI-Diffuser · Notebook Suite

Interactive notebooks for running experiments and exploring results for the
**M3-Score** project. They wrap the existing `experiments/` and `evaluation/`
code — no logic is duplicated, so results match the CLI.

## Quick start

```bash
pip install -r ../requirements.txt jupyter
jupyter lab        # or: jupyter notebook   (run from this folder or repo root)
```

Open **`00_index.ipynb`** first and run the environment-check cell.

## The notebooks

| Notebook | Purpose |
|---|---|
| `00_index.ipynb` | Overview, environment + dependency check, on-disk inventory |
| `01_explore_data.ipynb` | View real vs. generated MRI, collages, intensity histograms |
| `02_compute_metrics.ipynb` | Compute M3-Score / FID / KID / SSIM on a real↔gen pair, inspect per-layer M3 internals |
| `03_run_experiments.ipynb` | Launch any `experiments/` script (or the master orchestrator) with live output |
| `04_results_dashboard.ipynb` | Load + visualize every `*_report.json` already on disk |

## Shared config — `nb_config.py`

Every notebook starts with:

```python
import nb_config as C
C.setup()
```

Edit the defaults once at the top of `nb_config.py` and all notebooks follow:

- `REAL_DIR` — real images (default `data_mri/brats_axial_multislice`)
- `GEN_DIR`  — generated images (default `output/generated_500_best`)
- `RESULTS_DIR` — where reports/figures live

Handy helpers: `list_images`, `show_collage`, `find_reports`, `load_json`,
`show_pngs`, and `run_script(rel_path, args)` (streams a script's output inline).

## Notes

- Project root is auto-detected, so notebooks work whether the kernel starts in
  this folder or the repo root.
- Start metrics with a small `N` (e.g. 64) to smoke-test, then scale to 500.
- Notebooks were generated by `_build_notebooks.py`; re-run it to regenerate.
