# pyradiomics has NO prebuilt wheels on PyPI and is absent from conda-forge
# (win-64); the `radiomics` conda channel caps at Python 3.9. On Windows with
# Python 3.10 it must be compiled from source, which needs the MSVC toolchain.
# If `pip install pyradiomics` fails with "Microsoft Visual C++ 14.0 or greater
# is required" even though Visual Studio IS installed, setuptools is failing to
# locate it via vswhere. Build from a shell with the toolchain loaded:
#
#   call "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
#   set DISTUTILS_USE_SDK=1
#   set MSSdk=1
#   python -m pip install --no-build-isolation pyradiomics
#
# (--no-build-isolation is required regardless: pyradiomics' setup.py imports
# numpy and versioneer at build time, which PEP 517 isolation hides.)
